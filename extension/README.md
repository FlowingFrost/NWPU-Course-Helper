# 选课助手 · 浏览器插件（捕获教务开课信息）

浏览器插件负责：在教务系统「全校开课查询」页面上加浮动按钮，一键把当前页课程（或按课程代码静默查询）导入本地「选课助手」。**不接触账号密码**，只复用你在浏览器里已登录的会话。

## 目录

```
extension/
  manifest.json         MV3 清单
  build.mjs             esbuild 打包脚本
  src/
    scheduleText.ts     时间地点文本 → Segment[]
    jsonAdapter.ts      教务查询 JSON → 行
    domExtractor.ts     结果页 DOM → 行
    model.ts            行 → 候选 → add_course 命令
    messaging.ts        消息协议 / 设置
    background.ts       后台：转发到 http://localhost:3001/api/command
    content.ts          内容脚本：页面内嵌按钮 + 勾选导入 + 静默查询 + 预览
    preview.ts          迷你课表预览（复用 app 的 dayBlocks/layoutBlocks 布局）
    popup.{html,ts}     状态 + 打开全屏页
    options.{html,ts}   配置服务地址 / 默认类别
  test/                 核心逻辑单测 + 集成脚本（真实 HTML fixture）
  dist/                 构建产物（加载此目录）
```

## 一、构建

```bash
npm run build:ext      # 打包到 extension/dist/
```

（核心逻辑单测：`npm run test:ext`）

## 二、前置：启动选课助手服务

插件最终要把数据写入本地的选课助手，所以要先起服务：

```bash
# 在 WSL 的 CourseHelper 目录
npm start              # 或 npm run dev（开发模式）
```

启动后确认 Windows 侧能访问：在 Windows 浏览器打开 `http://localhost:3001` 应能看到选课助手页面。
若打不开（localhost 转发异常），改用 WSL IP：`http://172.31.2.39:3001`，并把插件设置里的「服务地址」改成它。

## 三、加载插件（Chrome / Edge）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本项目的 **`extension/dist`** 目录。
4. 工具栏出现「选课助手·教务捕获」图标即成功。

## 四、真机验证清单

> 插件按钮**直接嵌在教务页面里**（不再用悬浮窗）。既支持「独立标签页」打开，也支持「首页里内嵌 iframe」打开——`manifest` 已设 `all_frames: true`，两种方式都能注入。

### 4.1 批量导入勾选课程

1. 在已登录的浏览器打开教务「全校开课查询」，点「查询」出结果。
2. 在「已选 N 条」右侧会多出：**导入类型下拉（非必修/必修/内置）＋「导入选中」＋课程代码框＋「静默查询」**。
3. 勾选若干行（页面原来的复选框），点 **「导入选中」**：
   - 底部 toast：`已导入…：导入后共 N 门课`；
   - 打开 `http://localhost:3001`，课程面板应出现这些课（类别=你选的下拉值）。

### 4.2 单课一键加入候选 / 预览

- 每个课程行的**课程名右侧**会多出两个小按钮：
  - **「加入候选」**：把该教学班作为「非必修」一键导入。
  - **「预览」**：**鼠标悬停**它，弹出迷你课表——橙色=当前课程、实心=内置课、半透明=其它候选；当前课程与内置课时间重叠时会标 **⚠冲突**。移开即消失。

### 4.3 静默查询（按课程代码，结构化 JSON）

1. 在「课程代码」框填 `U01G11001`，点 **「静默查询」**。
2. 该课程**所有教学班**（不同老师/时间/容量）一次全部导入。

### 4.4 弹窗与设置

- 点工具栏图标：显示服务是否在线 + 「打开选课助手（全屏标签页）」。
- 「设置」：改服务地址；「加入候选」默认类别已改为页面内下拉（设置里的类别仅作兜底）。

## 五、故障排查

| 现象 | 排查 |
|---|---|
| toast「导入失败：…服务是否已启动」 | 选课助手服务没起；`npm start` 后再试 |
| 图标弹窗显示「未启动」 | 同上；并检查「设置」里的服务地址 |
| 服务地址 localhost 不通 | 改用 WSL IP（见 §二），保存后重试 |
| 点按钮提示「未找到课程行」 | 先点教务页「查询」让结果表格出现 |
| 静默查询提示「未找到学期选择器」 | 该页非「全校开课查询」标准页；换到 `/student/for-std/lesson-search` 页 |
| 静默查询「未查到该课程」 | 课程代码错，或该学期无此课 |

## 六、数据与权限说明

- 插件申请权限：`storage`（本地配置）、`tabs`（打开标签页）；`host_permissions` 仅限 `localhost`（本机服务）与 `jwxt.nwpu.edu.cn`（教务系统）。
- **不读、不存、不转发账号密码 / Cookie**；唯一外发目标是 `http://localhost:3001`（你本机）。
- 静默查询在教务页内**同源发起**，自动复用你已登录的会话，凭证不出浏览器。
- 插件代码为本项目自建，本地加载，未上架商店。
