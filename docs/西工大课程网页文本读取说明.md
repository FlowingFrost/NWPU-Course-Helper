# 西工大课程网页文本读取说明

> 适用范围：把从西北工业大学教务/选课网页**复制下来的课程文本**，解析并录入本工具（选课助手）的约定与规则。
> 本文是「西工大导入要求」的正式规则文档；WakeUp 文件格式的导入见 `DESIGN.md §11`。

---

## 一、导入要求（强制规则）

以下规则对所有「网页复制文本」录入一律生效：

1. **课程编号**：文本中 `U44G11034` 这类「大写字母 + 数字」的编号段，即课程编号（查重主键）。
   - 编号后紧跟的 `思想政治理论类`（课程类型）、`马克思主义学院`（开课学院）等中文段 → **忽略**。
   - 编号后的 `.18` 等「点 + 数字」后缀（课序号/班号）→ **忽略**。
2. **课程名称**：取独立成行的课程标题（通常为编号行之前的首行）。
3. **校区（关键规则）**：
   - `长安校区` 是**默认校区，录入时忽略**——不写入地点字段。
   - `友谊校区` 等**非默认校区，必须在地点字段中保留**，形如 `友谊校区 教X-XXX`。
4. **地点**：`教西B3-203` 这类「教学楼 + 教室号」，写入 `segment.room`。
5. **周范围**：`2~11周` → `startWeek=2, endWeek=11`（闭区间；跳周/断点拆成多条 segment）。
6. **节次**：`1-2节` 或 `第一节~第二节` → `startNode=1, step=2`（step 为连续节数）。
7. **星期**：`周一`=1、`周二`=2、`周三`=3、`周四`=4、`周五`=5、`周六`=6、`周日`=7。
8. **教师**：`丁社教` 或 `丁社教(1986000088)` → 取括号前名字；工号括号 `(1986…)` **忽略**。
9. **学分**：`学分(2.5)` → `credit=2.5`。
10. **已选人数/容量**：`已选学生数(92)` → `enrolled=92`；容量未给出时填 `0`。
11. **忽略项**（不参与建模）：
    - `2024;2025 本科` / `本科` / `研究生`（学年与培养层次）
    - `必修` / `选修` / `考试` / `考查`（课程性质与考核方式，仅作参考，不影响本工具的分类字段）
    - `总课时(40)` / `已安排课时(40)`（课时信息）

> 说明：本工具的分类字段 `category`（`builtin` / `required` / `elective`）由录入者**显式指定**，
> 网页文本中的「必修/选修」仅表示培养方案性质，不直接等于本工具的分类。

## 二、两种文本格式

### 格式 A：紧凑列表（列表页复制，每门课 4 行）

```
马克思主义基本原理
U44G11034.18
(2~11周) (1-2节) 长安校区 教西B3-203  丁社教
2024;2025 本科
```

- 第 1 行：课程名称
- 第 2 行：课程编号（忽略 `.18` 后缀）
- 第 3 行：时间段（周范围 + 节次 + 校区 + 地点 + 教师）；**该行可能没有星期**，星期需从页面上下文/分栏标题补全
- 第 4 行：学年与层次，忽略

### 格式 B：详情页（多行，含空行）

```
马克思主义基本原理

U44G11034思想政治理论类马克思主义学院

学分(2.5)总课时(40)已安排课时(40)已选学生数(92)

必修  考试

授课教师：丁社教(1986000088)

2024;2025 本科	2~11周 周二 第一节~第二节 长安校区 教西B3-203 丁社教;
2~11周 周四 第一节~第二节 长安校区 教西B3-203 丁社教
```

- 第 1 行：课程名称
- 第 3 行：课程编号 + 课程类型 + 开课学院（后两者忽略）
- 第 5 行：`学分(2.5)`、`已选学生数(92)` 等字段
- 第 9 行：`授课教师：丁社教(工号)` → 教师
- 第 11~12 行：若干条时间段，每条含「周范围 + 星期 + 节次 + 校区 + 地点 + 教师」，以 `;` 分隔多条

## 三、字段映射表

| 网页文本 | 内部字段 | 取值示例 |
|---|---|---|
| 课程名称 | `name` | `马克思主义基本原理` |
| `U44G11034` | `code` | `U44G11034` |
| `学分(2.5)` | `credit` | `2.5` |
| `已选学生数(92)` | `enrolled` | `92` |
| （未给出容量） | `capacity` | `0` |
| `周一`…`周日` | `segment.day` | 1…7 |
| `1-2节` / `第一节~第二节` | `segment.startNode` / `segment.step` | 1 / 2 |
| `2~11周` | `segment.startWeek` / `segment.endWeek` | 2 / 11 |
| `教西B3-203` | `segment.room` | `教西B3-203` |
| `友谊校区 教X-XXX` | `segment.room` | `友谊校区 教X-XXX`（校区保留） |
| `丁社教` | `segment.teacher` | `丁社教` |

## 四、完整示例：马克思主义基本原理

把「格式 B」文本录入为内置课（`category: "builtin"`，单候选且 `selected: true`），结果为：

```jsonc
{
  "id": "crs_u44g11034",
  "code": "U44G11034",
  "name": "马克思主义基本原理",
  "category": "builtin",
  "credit": 2.5,
  "willingOverride": null,
  "color": "#ef5350ff",
  "options": [
    {
      "id": "opt_u44g11034",
      "label": "丁社教 班",
      "rating": 0,
      "selected": true,
      "enrolled": 92,
      "capacity": 0,
      "segments": [
        { "day": 2, "startNode": 1, "step": 2, "startWeek": 2, "endWeek": 11, "room": "教西B3-203", "teacher": "丁社教" },
        { "day": 4, "startNode": 1, "step": 2, "startWeek": 2, "endWeek": 11, "room": "教西B3-203", "teacher": "丁社教" }
      ]
    }
  ]
}
```

- `长安校区` 被忽略，地点仅存 `教西B3-203`；若为 `友谊校区`，则 `room` 应为 `友谊校区 教X-XXX`。
- 两条 segment 分别对应「周二 1~2 节」与「周四 1~2 节」，周范围均为 2~11 周。
